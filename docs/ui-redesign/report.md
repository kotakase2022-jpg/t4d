## 2. 変更した画面

78 ルートすべて（各ルートを 1 スライスが担当）と新規 3 ルート（指標マスターの登録・編集、収集キャンペーンの作成を Modal から専用ページへ）。
Changed 45 画面・OK 36 画面（`regression.md` §1）。主なもの:

- **ホーム**: 役割別（入力担当・作成担当・レビュー担当・承認者・管理者・閲覧者）。先頭に「要対応」（Attention）→「自分が次に行う作業」
  （Action。primary は「最初の作業を開く」1 つ）→「はじめに」（3 手順）→ 既存の KPI（Status）→ 拠点別進捗・タスク（Insight）
- **非財務データ**: DataTable の基準実装。主操作 1 つ＋「その他」（前年度から複製・CSV・XLSX）、低頻度の列（期間・検証・根拠資料・更新日時）は
  列の設定へ、保存ビュー、選択時だけ出る一括操作バー（差戻しは理由必須・確認つき）
- **データの詳細・回答・原稿・調書・PBC**: 状態 × 権限で primary が 1 つに決まる（`src/lib/ui/state-actions.ts`）
- **SSBJ・CSRD**: 要求事項一覧の既定列を絞り、詳細は「適用の根拠 → 3 観点 → AI 候補（採用は人）→ 対応計画 → 回答」の順に
- **組織・拠点**: 6 節を段に分け、19 項目の指標マスターのフォームを専用ページへ
- **監査法人**: メニューを 計画／実施／結論／記録 に再編（案件未選択時は 2 項目）、ホームに要対応と作業、サブ画面の見出しを画面名に
- **設定**: 5 つのタブ。入口は従来どおり企業管理者のみ

## 3. UI をどう簡素化したか

- **主操作は 1 つ**: `Button` の既定を secondary にし、primary は明示。見出しは `PageActions`（primary 1・secondary 最大 2・残りは「その他」）
- **文脈で変わる操作**: 未選択は新規・検索・絞り込み、行は `RowActions`、選択時だけ `BulkActionBar`、状態ごとに出す操作を変える
- **危険操作の 3 区分**: 取り消せない（範囲と影響を示す確認）／一括・上書き（件数と内訳を示す確認、差戻しは理由必須）／取り消せる（実行後に「元に戻す」）
- **文言**: 内部コード・英語のシステム語を業務用語へ（例: Validation Error → 検証エラー、Evidence 不足 → 根拠資料の不足、権限キー → 「〜を管理する権限が必要です」）
- **状態**: 状態の表示を登録簿（`src/lib/ui/status`）に一本化し、ラベル＋アイコンで統一
- **空・エラー・読込**: 空状態は次の操作を必ず示す。エラーは何が・なぜ・どう直すかを示し、業務エラーは元の画面に出す。
  遷移中は上端のプログレス、表は固定高のスケルトン
- **密度**: 余白は増やさず、装飾の Card を Section に変えて枠を減らした

## 4. Progressive Disclosure した機能（L2・L3 へ）

- L2「その他」: CSV・XLSX・Word の出力、前年度から複製、過去回答の取込、デモの初期化（ホーム・サプライヤー取込）、データセットの ZIP
- L2 行の操作・一括操作: 編集・削除・差戻し・承認・再付与・チームから外す など
- L2 折りたたみ: 説明文、低頻度の絞り込み（原稿タブの「その他の絞り込み」など）、低頻度の列（列の設定）
- L2 作成パネル（`?new=1`）: 一覧の上に常時出ていた作成フォーム（保証契約・指摘・PBC・レビュー Note・資料・KPI 目標）
- L3: Command Palette（Ctrl/Cmd+K。最近使った画面・役割別おすすめ・操作・全画面・設定・データ検索）、ショートカット（`g`＋キー、`?` でヘルプと用語集、`/` で検索）

## 5. Smart Default にした項目

対象年度（ヘッダーの期間）、担当拠点で絞った一覧（入力担当）、期限（報告期間の提出期限）、担当者（本人）・担当部署（評価の部署）、
CDP 過去回答の取込先（直前の期間）、新しい報告期間（最新＋1 年）、新しい拠点の親・国・通貨（親から継承）、データの単位（指標の単位）、
前年の値の参照表示、資料の文書種別・発行日（ファイル名から推定して空欄だけに入れる）、保証契約の対象期間・保証水準・基準、PBC の期限、
サンプル抽出の件数と Seed、表示件数（25／50）、設定・CSRD 設定の開く節（未完了の最初の段）。

## 6. Navigation の変更

- 既存の 2 つのメニューの形と、これまでの明示要望（SSBJ・CSRD の 6 項目と定性情報、「分析」の位置と 5 項目、GHG › Scope3データ取込 › Cat.1）は不変
- 追加: グループの開閉（利用者ごとに記憶）、開示の閲覧権限が無い役割は開示のグループを既定で閉じる、パンくずをメニューから生成、
  ヘッダーの「検索 Ctrl K」
- 監査法人のメニューを 計画／実施／結論／記録 に再編
- 出力の権限が無い役割には出力の項目を出さない（押すと権限エラーになっていたもの 3 件）

  DB スキーマ・マイグレーション・API ルートは変更なし
