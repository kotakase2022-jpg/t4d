## 要件 ID の付与方針

- **機能要件一覧 v0.2** は正本側で既に ID が振られている（`UX-P0-001` 〜 `GLOBAL-P3-001`、計 118 件）。
  QA ではこの ID をそのまま使う。
- **開発指示書** には ID が無いため、QA 側で `INS-<章>-<連番>` を付与した。
  例：`INS-08-012` = 指示書 8 章「必須 Route」の 12 番目。
- 指示書 23 章「Definition of Done」は `DOD-01` 〜 `DOD-30`。
