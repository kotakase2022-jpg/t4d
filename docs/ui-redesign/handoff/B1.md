## 4. 判断した点・やっていないこと

- **取込の拠点の既定（D2 の後半「全社なら自動判定」）は変えていない**。この既定値は AI の仕分けで「行に拠点が書かれていないときの割り当て先」にもなる（`mock-provider.ts` の defaultUnitCode）。全社スコープの既定を「自動判定」へ変えると、拠点の列が無いファイル（50 ファイル・異種データ）の行が拠点未選択になり取込の結果が変わる。E2E で確かめられないため、選択欄に「行に拠点が書かれていないときの割り当て先です」を添えるだけにした。担当が 1 拠点の利用者はその拠点が既定（従来どおり）
- 一括の差戻しの理由（§3.1-4）
- `KNOWN_MENU_DENIED` の標準 CSV（§2）
- 「アラート」は組織の注意の一覧のまま（ホームの Attention は利用者の担当の注意で、母集団が違う）。帯に「承認後に変更されたデータ」を足して同じ事実を同じ名前で出した
- `AI_HANDOFF.md` は並行作業の衝突を避けて触っていない（Stage C がまとめて追記する）
